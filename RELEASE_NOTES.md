# niri-pip v0.2.1

First public-ready release of the verified controller core.

Highlights:

- Chromium PiP detection even when Niri reports an empty `app-id`;
- free-form manual size that survives daemon restart;
- workspace follow without focus stealing;
- runtime follow on/off and multi-monitor follow policies;
- PiP-only opacity control;
- geometry lock/unlock, position presets and pixel nudging;
- generic pin/unpin for normal windows;
- optional MPRIS media control;
- English/Russian controller UI and documentation;
- systemd autostart, desktop launcher and safe iNiR integration;
- source and prebuilt release installers;
- live verification on Arch Linux + Niri 26.04.

See `VERIFICATION.md` for the tested matrix and `README.md` / `README.ru.md` for usage.
